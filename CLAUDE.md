# Stargazer

A single-file web page (`site/index.html`, no build step, no dependencies) that shows saved Reddit posts as a bento gallery.
Hosted on GitHub Pages. Accounts and storage come from Supabase (free plan). The page is public; the data is not.

## Layout
- `README.md`  user-facing (what Stargazer is, quick start, local use, standalone download). Keep it free of deploy instructions; those live in `docs/SELF-HOSTING.md`. Keep its feature and privacy claims true when behaviour changes.
- `site/index.html`  the whole app (HTML, CSS, JS). `site/config.js` holds the Supabase URL and anon key (safe to publish; Row Level Security protects data).
- `supabase/schema.sql`  table, row-level security and the `merge_posts` function. Run once in the Supabase SQL editor.
- `supabase/functions/redgifs/index.ts`  optional Edge Function (deployed by hand, Verify JWT off): looks RedGifs clips up for the page when the browser cannot reach the RedGifs API ("Failed to fetch"). The page tries RedGifs directly first, then this helper.
- `tools/screenshots/`  regenerates `docs/screenshots/*.jpg` for the README from invented posts and generated artwork (`make_images.py`, then `shoot.py`). Re-run after visible UI changes. Never use real posts or accounts.
- `tools/hot_relay.py`  optional local relay that lets the page read Reddit's real hot feed (browsers cannot call Reddit directly).
- `.github/workflows/`  `pages.yml` deploys `site/`; `keepalive.yml` pings Supabase so the free project is not paused.
- `tests/`  Playwright checks (`merge_test.py`, `nsfw_test.py`, `panels_test.py`, `lists_test.py`, `reset_test.py`, `viewer_yt_test.py`, `wayback_test.py`, `gone_pic_test.py`, `audio_test.py`, `unload_test.py`, `cloud_reload_test.py`, `first_load_test.py`, `stats_test.py`, `intro_test.py`, `nav_test.py`, `view_test.py`, `sound_follow_test.py`, `layout_test.py`, `merge_prompt_test.py`, `localmeta_test.py`, `imgpause_test.py`, `rg_embed_test.py`, `polish_test.py`, `regrab_test.py`, `review_test.py`, `header_test.py`, `tilesize_test.py`, `seenimg_test.py`, `sort_test.py`, `links_test.py`, `reader_test.py`, `status_clear_test.py`, `signout_others_test.py`, `subsel_test.py`, `nsfwcount_test.py`, `rg_helper_err_test.py`, `reveal_touch_test.py`, `texttitle_test.py`, `listtext_test.py`, `uxpass_test.py`, `rgviewer_test.py`, `autoplayall_test.py`, `ctlfit_test.py`, `touchpin_test.py`, `layer_test.py`, `prefs_test.py`, `uxfix_test.py`, `trayrow_test.py`, `gifstill_test.py`).

## Rules that must not be broken
1. **No personal data in the repo.** No saved-post lists, no CSV files, no subreddit lists from a real account, no keys other than the Supabase anon key. `.gitignore` blocks `*.csv` and `local/`.
2. **Never add the Supabase `service_role` key anywhere.**
3. **Data scheme** (CSV and database): `id, permalink, starred, updated, deleted`. `updated` is the ms time of the last change to that post; `deleted=1` is a tombstone that is kept forever.
   Merge rule, in `pickRec` / `mergeSets` in the page and in `merge_posts` in SQL (keep them identical): newer `updated` wins; on a tie a tombstone beats a live row; two live ties keep the star if either has it.
   A post with a tombstone must never be revived by an older copy.
   A manual NSFW override is stored in the permalink as `?nsfw=1` / `?nsfw=0` (see `nsfwMark`, `toggleNsfw`); no mark means the automatic guess. Keep it in the permalink so the columns and the database schema do not change.
4. Every edit must stamp the record (`nowT`) and call `markDirty`; deletions go through `deleteRows`.
5. The page must keep working with no `config.js` values (accounts hidden) and from `file://`.

## Working notes
- The top bar has two floating panels: **Filters** (`#panel`, what is shown) and **Source** (`#srcpanel`, which list, sign-in, sync, Subreddit mode). Opening one closes the other. Keep source/account controls out of Filters. The Source switch and list tools come first in the Source panel; the Account block (sign-in, marked Optional) follows as a folded section, then Advanced (RedGifs helper status). A list is either **Local** (this browser or a linked file) or **Account** (`rec.cloud`, synced); `csvInfo` shows which, and `#csvCloud` switches it.
- Navigation: `#navbtns` holds Source, Filters, Shuffle and Search. On wide screens it is `display:contents` inside the top bar (labelled buttons, search box always visible); on phones it is a fixed bottom bar and the panels open as bottom sheets. The top bar loses its `backdrop-filter` on phones because a blurred parent would trap fixed children.
- The Active / Loaded / Total strip lives in the top bar; on phones it sits right-aligned beside the logo (number over label, 12.3k style for big counts; with nothing filtered and nothing still loading it shows one number labelled Posts, `body.stats-flat`). A refresh keeps filters and scroll for the tab (sessionStorage only; NSFW never persists to a later visit).
- The Filters panel has two columns: **View** (Layout, Tile size, Columns, Card info & controls, Auto-play, Theme) and **Filter and sort** (Sort, Time range, Subreddit, NSFW, Show text posts, Starred only, Hide broken media), then Browse chips.
- Layouts (first in the Filters panel's View section, `LAYOUT` / `layoutCard` / `paintLayout`): **Masonry** (default, best for media), **Grid** (equal squares) and **List** (short rows on a solid surface with a small square thumbnail on the left and the text beside it, purple/magenta accents, no playback or media controls, card info always shown; the Card info & controls setting does not apply there).
- The page is one file on purpose. Search by function name (`syncCloud`, `mergeSets`, `fillCard`, `openViewer`, ...).
- Never show a person an archive's raw API/JSON address (`isApiUrl`), and do not link to Reveddit (it depends on Reddit's closed API and just errors). Posts recovered from Arctic Shift or PullPush open in the built-in reader (`openReader`, `hasReader`: title, author, score, saved text `m.x`, and comments loaded on request from Arctic Shift's comments search); Wayback-recovered posts link straight to their snapshot (`m.wb`); anything else gets the Wayback address (`wbPostHref`). The comment count and the Comments button always go to the Reddit page first (the thread is often still there, even for removed posts); the reader only offers loading comments from the archive as a fallback.
- Status text (`loadText`, `recText`, progress bar) belongs to one list: `clearStatus()` runs from `resetView` (every list change, unload, sign-out) and the recovery's `status()` ignores writes from a stale run (`gen!==loadGen`).
- Archive APIs (Arctic Shift, PullPush, Wayback) are rate limited; requests go through `timed()` / `apiRetry()` with per-host spacing and back-off. Do not add direct `fetch` calls to them.
- A tile never shows a playing GIF by itself: an animated file (`isAnimUrl`: a `.gif` that is not a `preview.redd.it` copy, which is a still) is ordered after every still candidate in `imgCandidates`, and if it is the picture that loaded it is frozen on its first frame (`freezeFrame`, a `canvas.still`). Hover / in-view play and the viewer still use the real file (`gifstill_test.py`).
- Images load through the `IMGQ` queue (limits concurrency, pauses on bursts of failures, shows a countdown). Pictures that loaded before (`SEEN`, short hashes in `saved-posts-seenimg`) skip the queue's pacing so a refresh shows them at once from the browser cache.
- On touch screens Show on hover / focus means the tile in focus (`.is-focus`) shows its layer; Show always shows all.
- Touch screens use touch events for pinch/zoom in the viewer; mouse and pen use pointer events. A text-only post (`.is-text`) has no picture to say what it is, so while its layer is down it keeps just its title on the tile (`.peek`), on a lavender tile (`--lav`) with a faint picture mark instead of words.
- Test by loading the page in Playwright with network routes mocked (see `tests/`). There is no live access to Reddit or the archives from the dev sandbox.

- Deleting a single post (or several, via **Bulk Actions** mode) has no confirm for single deletes: it shows a toast with **Undo** (`toast(msg, {label, fn})`, `restoreRows`). Bulk delete asks once, then also offers Undo. Selection mode (`SEL`, `selMode`, `selAct`) acts on `list`; its action bar `#selbar` lives inside `.deck`: on desktop a tinted strip under the top bar, on phones a fixed bottom sheet; NSFW changes go through `markNsfw` (no commit) so many posts commit once.
- What is remembered: tab-only (sessionStorage, `saved-posts-view`) are filters, search, subreddit, range, scroll; browser-wide (localStorage) are Theme, Layout (per list), List columns, Card info & controls, Auto-play options, volume, **tile size** (`saved-posts-tile` desktop px, `saved-posts-tile-phone` column step) and per-list **sort, Starred only, Show text posts once toggled** (`saved-posts-listprefs`, `saveListPrefs` / `applyListPrefs`, applied in `startCsvMode`). NSFW and search text never persist to a later visit.
- A CSV or account list opens sorted **Newest posts** (set in `startCsvMode`; Saved order stays in the Sort menu); Subreddit mode opens on Hot. The Filters badge counts only settings changed from the defaults. Theme lives in the Filters panel's View section (it is about how things look, not which list). Layout is remembered per list (`saved-posts-layouts`, `applyListLayout`) with the global value as the default.
- The Subreddit dropdown (`#subsel`) is rebuilt by `buildSubs()` from `refresh()` whenever the list or chosen subreddit changes; a subreddit name on a card filters the list (tooltip, hover underline, toast with Show all; clicking the same name again clears it), it never opens Reddit. The filter is shown in the search box as an `r/name` word (`boxText`, `syncBox`, `setSub`); typing or deleting that word changes the filter, anything else in the box is the text search. `state.sub` can hold several subreddits joined with `+` (typed as `r/a+b` or `a+b`, every name must be in the list; `subIn` does the matching).
- The viewer has previous/next **post** navigation (`viewerPost`, Up/Down or Left/Right arrows, swipe, bottom buttons) separate from the gallery's image arrows.

- User-facing wording says **NSFW** (the Filters panel carries live counts beside NSFW and Show text posts, `#nsfwcount` and `#textcount`, set in `updateChips`); the card toggle shows it stacked on two lines (NS over FW). The filter modes are Hide / Blur / Show / Only. In Blur mode a mouse hover unblurs a tile (`@media (hover:hover)` only, because a tap leaves a touch card "hovered"); on touch the Reveal/Blur button toggles `.show` and remembers the post in `REVEALED`, so a card rebuild (`fillCard`) keeps it revealed; changing the NSFW mode clears it.
- List on desktop has a **Columns** choice (1 / 2 / 3 / Auto, `LCOLS`, `paintCols`, remembered in `saved-posts-listcols`); a fixed count also caps each column's width so rows stay easy to scan. Default is Auto. Desktop List uses a 20px column gutter (`--lgap`) against the 6px row gap; row spans are computed from the row gap, so leave that alone.
- **Show text posts** defaults to on in List and off in Masonry/Grid (`textDefault`, `applyTextDefault`) until the person toggles it (`textTouched`, kept in the tab's view state); the Layout hint (`paintLayoutHint`) adds a "Text posts default to off in this view" note under Masonry/Grid while text posts are off.
- The Source panel always shows a loud "Last pulled from Reddit" line under the list blurb (`#pullLine`, set in `updateMergeHint` from `saved-posts-lastmerge`; Reddit's export has no date inside, so the date is the file's modified time (`pullTime`) when a raw Reddit CSV is opened or merged; a file this page wrote (has an `updated` column) says nothing, so such a list shows "date unknown" with its first-opened date; the next raw Reddit CSV opened or merged sets it. There is deliberately no manual date control). Over 30 days it turns red and the merge prompt (`#mrgHint`, Reddit data-request link, Merge CSV, Remind me later) shows too.
- Source panel order: list picker, then the list's facts (`.listfacts`: count blurb, Local/Account note, last pulled; plain muted text, not pills, because they are not controls), then at most one warning (the stale-pull prompt `#mrgHint` wins over the backup hint `#expHint`), then the actions. Pills and fills are for things you can press; warnings alone get colour boxes. A dot on the Source button (`data-attn`, `updateSrcDot`) shows when a warning is waiting inside the closed panel. With no list, Shuffle is disabled (`.no-data`); the first-run screen reads pitch, then steps, then Open CSV. Phone sheets have a handle and scroll shadows.
- Card buttons: the bookmark (`.save`) means "in your list" and removes the post (label "In your list: tap to remove"; the first removal's toast also explains it); a starred card gets a white filled star; the media label (`.badge.media`) is plain text, since only the buttons are controls.
- Unloading the last list leaves an empty placeholder list (`builtin-*`); `isEmptySlot` makes the selector say "No source loaded", the blurb say so, and hides the Local/Account note.
- While previews load, a small magenta dot (`.loaddot`, before `#loadText`) breathes and sends out a soft ring (`dotbreathe`, `dotring`: scale and opacity only, so it stays smooth); it exists only while `body.previews-loading` is set (so the text is flush left otherwise), is centred on the text line (`.load` aligns items centre) and fades in.
- In the viewer, RedGifs' own player (`iframe.vrg`, the fallback when the clip cannot be fetched directly) has its controls along the bottom, so the stage gives up a band for the previous/next post buttons (`.vstage:has(iframe.vrg)`) rather than letting them sit on the scrubber.
- **Card info & controls** (`#cardmode`; `cm-collapsed` / `cm-hover` / `cm-always` on the body, `saved-posts-cardmode`, an old `saved-posts-ctlmode` carries over) is the one setting for what a Masonry/Grid tile shows beyond its media. Each card has one glass **layer** (`.layer`: the info block, the Source and Comments buttons (`.actions`), the action pill `.lay-cap` (NSFW / star / bookmark / full screen), and `.lay-play` where `buildControls` puts the player controls). Collapsed: media only, with a faint handle (`.lhandle`, lower part of the tile) that opens that card's layer (`setLayer`, class `.lay-open`; the grabber `.lh-close` at the layer's top closes it; swipe up on the handle opens, I toggles the hovered / focused card, Esc, a tap elsewhere, opening another card, or scrolling the card out of view closes it). Show on hover / focus: the layer rises with the pointer (the focused tile on touch). In every mode the layer can be put away by hand (`toggleLayer`, `layerUp`, class `.lay-shut`): tap the tile, tap or swipe down the grabber, or press I; the handle comes back to raise it again. A hand-shut card stays shut until it is tapped or its handle used (Show on hover / focus also clears it when the pointer or focus leaves the card; a mode change clears all). Show always: up on every card. The badges and placeholder label follow the layer. In List the layer boxes are `display:contents`, so the row keeps its own arrangement (info text and round buttons positioned on the card, setting row hidden). Closed layers must not catch taps (`.layer *` inherits `pointer-events`). Tiles narrower than 300 / 200 / 140px (container queries on `.card`) condense the layer (smaller buttons, one-line title, no meta). There is no hairline progress or bare player bar on a tile any more (`ctlfit_test.py`, `layer_test.py`).
- In Masonry / Grid a plain click or tap on a tile toggles its layer (`a.thumb` click handler in the grid listener) instead of opening the post; the **Open post** button in the layer (first, then Comments; it goes to the post, and is not the top bar's Source, which is the list; the pill on the right in the order NSFW, Favourite, Saved, Full screen) goes to the post, and modifier-clicks and List keep the plain link. Double tap (or double click) on a tile that has player controls pauses or resumes it (`pp.click()`); a single tap on those toggles the layer after 360ms (`card._tapT`; the window is generous because real double taps are slow). On the narrowest tiles (<=140px) the layer drops the title, Comments and the NSFW button so it still fits.
- The handle and grabber are small centred targets (72px wide) with `touch-action:none`, and the scrubber has `touch-action:pan-y`, so a scroll that starts on a tile or tray scrolls the page instead of opening the tray or scrubbing. Sound control on a clip (`.volwrap` in the player controls): one press on the muted speaker turns sound on; after that each press opens or closes a vertical volume flyout (`.volfly`, a rotated range input, class `.open`; drag to the bottom to mute; it also closes on an outside click or when the layer closes). There is no inline horizontal slider, so the scrubber gets the room.
- On touch, tapping the layer, the handle or the chevron pins that card as the focused one (`pinned`, in `pickFocus`) until it is wholly scrolled out of view or the page moves more than 120px, and nothing overrules it in the meantime (`touchpin_test.py`).
- **Autoplay all media in viewport** (`#autoplayall`, `auto.all`, `saved-posts-autoplayall`, off by default, with a standing warning line) plays every clip and embed whose tile is in view (no `MAX_AUTO` cap, YouTube/RedGifs included, touch too) and stops them as they leave; the older **Auto-play in view** stays the capped, embed-free option. 
- Tile size is a free slider on desktop; on phones (<=720px) it snaps to the column counts that fit (1, 2, 3 across) with a notch and number each (`buildSizeControl`, `SIZE_STEPS`).

## Deploying
Push to `main`; `pages.yml` publishes `site/`. Settings needed once: Pages source = GitHub Actions; Actions secrets `SUPABASE_URL`, `SUPABASE_ANON_KEY` for the keepalive.

## UX pass notes (Oct 2026)
- First run offers **Try sample posts** (`openSample`, `SAMPLES`, `sampleArt`): twelve invented posts with generated SVG artwork as `data:image/` thumbnails (`imgCandidates` / `buildChain` accept `data:image/` for this), saved as an ordinary Local list flagged `rec.sample` (no backup or last-pulled warnings). Never use real posts there.
- Keyboard: a Masonry/Grid card is one tab stop (its picture). Enter or Space on it moves into the card's own controls (`kbOpen`, `cardTabs`); Esc or leaving the card tucks them away again (`kbClose`). List keeps every control tabbable. The tile's aria-label says "Show details and controls" in Masonry/Grid and "Open" in List. There is one visually hidden `h1`.
- On phones the Filters sheet opens on Filter and sort, then Browse, then the View settings (CSS `order` in the 720px block). A mouse in Show on hover / focus gets no handle on tiles (it hovers); touch keeps it, and shows a one-time hint (`saved-posts-trayhint`, cleared by opening any card's tray).
- Motion: one `--ease-out` token; pressed controls dip with `scale:.97` (not under reduced motion); plain hover colour rules on controls sit inside `@media (hover:hover)` so a tap does not leave them stuck.
- The unbacked-up warning carries an **Export now** button (`.expnow`, clicks `#csvExport`).
- Second audit: counts use `fmt` (1.2M, 13k) and "1 comment"; title links carry the full title in `title`; list rows let the subreddit and date shrink with an ellipsis instead of cutting the line; the empty result state has its own **Clear filters** (`#emptyClear`); buttons inside a layer have no backdrop blur of their own. Phone layer: `viewport-fit=cover` (the top bar pads with `env(safe-area-inset-top)`), `theme-color` meta tags follow the page background (`syncThemeColor`, including a theme chosen in the page), `touch-action:manipulation` on controls, and 16px form fields on coarse pointers (stops iOS zooming on focus). None of this could be checked on a real device.
- Tray row: Open post, Comments and the NSFW / star / bookmark / full-screen pill are always **one line** (`.lay-act` is `nowrap`; `trayrow_test.py` walks tile widths from 3-across phone to wide desktop). Tray controls are **bare icons** (no circles, no pill; the glass tray is the only surface; sizes are `--lw` x `--lh` with glyph `--gi`). Below a 380px tile the two links become icons (`.bt` label hidden, `.bi` icon shown; the names stay in `aria-label` and `title`); state is shown by the glyph (star: outline off, filled and tinted with `--hot` on; bookmark filled; NSFW dim when off). In icon mode (tiles <=380px) `.actions` and `.lay-cap` are `display:contents` and the row is `space-between`, so every icon is evenly spread across the tile and on one centre line (`trayrow_test.py` measures pitch, centre line and margins); the star is a drawn mask icon (`--ico-star`, `--ico-star-on`; its text glyph stays for state, `font-size:0`) because a text glyph sits at a different height in every font. Every button has an invisible ~44px tall catch area (`::after`). Below 200px the NSFW button leaves the tray (per-post marking stays in Bulk Actions and on tiles 200px and wider); on <=140px tiles `--lw` follows the tile (`cqw`) and the title row goes. 3-across tray is about 36px tall.
- **Shortcuts and gestures** (`details#kbhelp`, `.kbhelp`) is a quiet, collapsed-by-default fold at the bottom of the Filters panel (last on phones too, via `order:1`). Plain muted text with small `kbd` keys, two columns (Keyboard; Touch and mouse). When a shortcut or gesture is added or changed, update this list (`uxfix_test.py` checks it exists, is closed and comes last).
- Reduced motion keeps fades, colour changes and a pulse for "working", and drops sliding, scaling and spinning (the layer fades without rising, panels fade in, the sync spinner pulses, smooth scrolling becomes instant). Do not go back to `transition:none` on everything.
